# 困ったときは

- **インストーラーを選べない**: Windows の「システムの種類」が「x64 ベース」の場合は x64 版、「ARM ベース」の場合は ARM64 版を使います。
- **文字化けする**: 対応している文字コードは UTF-8、UTF-8 BOM、UTF-16 LE／BE、UTF-32 LE／BE、Shift_JIS、EUC-JP、ISO-2022-JP です。自動判定できない文字コードのファイルは、あらかじめ対応形式へ変換してください。
- **書き込み中のログを開きたい**: 書き込み元のアプリが読み取りを許可していれば、そのアプリを終了せずに開けます。読み取りを許可していない場合は、書き込み元がファイルを閉じてから開いてください。
- **更新を確認できない**: インターネット接続を確認し、「設定」→「更新と情報」から再度確認してください。
- **動作状況を確認したい**: ログは Windows では `%LocalAppData%\Fumilume\logs`、macOS では `~/Library/Application Support/Fumilume/logs` に日付ごとに保存されます。問い合わせ時に該当日のログを添付すると原因を確認しやすくなります。
- **不具合や要望を伝えたい**: [GitHub Issues](https://github.com/1llum1n4t1s/Fumilume/issues) から報告できます。
