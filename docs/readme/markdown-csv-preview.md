# Markdown / CSV のプレビュー

`.md` ファイルではツールバーのプレビューボタン、または `Ctrl+Shift+M` で編集画面とプレビューを切り替えられます。

## CSV

CSV をExcel風の行番号・列名・罫線付きの表でプレビューします。「プレビュー」ボタンまたは `Ctrl+Shift+M` で切り替えます。セルをダブルクリック、または選択して `Enter` / `F2` で値を修正し、「適用」または `Ctrl+Enter` で反映、`Esc` で取り消します。入力欄では `Alt+Enter` で改行、`Enter` で適用して下へ、`Tab` / `Shift+Tab` で適用して左右へ移動します。適用後は通常の保存・元に戻す・やり直しを使えます。先頭行もデータとして表示し、先頭のゼロや数式の文字列をそのまま保持します。

- 未適用の入力は表示・タブの切り替えで取り消されます。修正は適用してから `Ctrl+S` で保存してください
- 行番号・列名をクリックすると行・列全体を選択できます。`Shift`＋クリックで連続する複数行・列を選び、`Ctrl+C` でExcelなどに貼り付けられるタブ区切り形式でコピーできます
- セルはクリック、`Shift`＋クリック、ドラッグで範囲選択できます。矢印や `Tab` で移動し、`Shift`＋矢印で範囲を広げられます。セル内の文字だけを選ぶ場合は `Alt`＋ドラッグを使います
- 選択範囲を `Ctrl+C` / `Ctrl+X` でコピー／切り取り、選択範囲の左上へ `Ctrl+V` でExcelの表を貼り付けられます。足りない行・列は補完します。`Delete` / `Backspace` は値だけを消し、`Ctrl+D` は最上行、`Ctrl+R` は最左列の値を範囲内へ繰り返します。セルの右クリックからも操作できます
- 見出しを右クリックすると、選択した行・列の前後への追加、削除、コピーを実行できます。複数行・列の選択中は同じ数だけ追加します。空のCSVにも行・列を追加できます。末尾への追加はコマンドパレットからも実行できます
- 列見出しを右クリックして、選択した1列を基準に全行を昇順・降順へソートできます。先頭行を見出しとして固定する操作も選べます。数値は数値順、文字は英字の大小を区別しない文字列順に並べ、空欄は常に末尾、同じ値の行は元の順序を保ちます。列指定のソートはコマンドパレットからも利用できます（列番号を入力するためマクロ記録の対象外）
- 列見出しの右端、行見出しの下端をドラッグして列幅・行高を調整できます。サイズは開いているタブごとに保持し、CSVファイルには保存しません
- プレビューは先頭1,000行・100列まで表示し、超過時は画面に案内します。上限外に追加した行・列は「編集へ戻る」で確認・編集してください。追加位置やファイル自体の内容は変更・省略しません
- 閉じていない引用符がある場合は警告します。「編集へ戻る」で引用符を修正してから表の操作を再試行してください。大きなCSVの解析・コピー・範囲編集・行列操作中も画面操作を継続できます。処理中に本文や選択を変えた場合は操作を中止します
- 列の追加・削除・コピーは表示上限より後ろの行にも適用します。行コピーも表示上限より右の列を含みます
- コピー・範囲編集・行列操作は、本文と貼り付け内容および結果が各8,388,608文字（UTF-16単位）、解析するセル数と編集後のセル数が各1,048,576個までです。超過時は内容を変更せず案内します。「編集へ戻る」で編集してください
- CSV表示中はテキスト行の削除・複製などを無効にします。テキスト操作を含むマクロは編集画面へ切り替えて再生します
