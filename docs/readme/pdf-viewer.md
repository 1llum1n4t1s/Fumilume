# PDF の表示

`.pdf` ファイルは読み取り専用のタブで開き、ブラウザの PDF 表示と同じように全ページを縦につなげて表示します。そのままスクロールすると次のページが続けて見られます。最初は表示領域の幅に合わせて表示し、倍率の隣にある「高さに合わせる」「幅に合わせる」で切り替えられます（ウィンドウのサイズ変更にも追従します）。拡大・縮小ボタンや倍率表示（100% に戻す）を押すと固定倍率になります。

ツールバー左のページ番号欄に数字を入力して Enter を押すと、そのページの先頭へ移動します（Esc で入力を取り消します）。左右のボタンは前後のページの先頭へ移動します。表示部分にフォーカスがあるときは、PageDown / Space で 1 画面下、PageUp / Shift+Space で 1 画面上、↑ / ↓ で少しずつ、Home / End で先頭・最終ページへ移動できます。コマンドパレットの「PDF の指定ページへ移動」でもページを指定できます。前回のタブを復元するときは、終了時の表示方式と表示していた位置を引き継ぎます。

PDFでは文字をドラッグして選択し、`Ctrl+C`（macOSでは`⌘C`）または右クリックの「コピー」でコピーできます。`Ctrl+A`（`⌘A`）で、そのページの文字をすべて選択します。選択は1ページの中だけで、ページをまたいで選択することはできません。スクロールや拡大・縮小では選択は解除されず、別のページの文字以外をクリックするか `Esc` を押すと解除されます。画像だけのPDFやコピーが禁止されているPDFでは、文字を選択できません。
