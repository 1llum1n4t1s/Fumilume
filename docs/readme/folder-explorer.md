# フォルダを開く

左サイドバーは上下に分かれ、上に縦タブ、下にエクスプローラーを表示します。未選択時の「フォルダを開く」ボタン、コマンドパレット（`Ctrl+Shift+P`）の「フォルダを開く」、または `Ctrl+K` のあとに `Ctrl+O` を押してフォルダを選びます。Macでは `⌘K` のあとに `⌘O` を押します。フォルダを開き直しても編集中のタブは残り、閉じるとフォルダ選択用の画面へ戻ります。

- フォルダ名や矢印をクリックして展開します。フォルダを先に、ファイルを名前順に表示します。
- ファイルの1クリックは斜体の一時タブで開き、次のファイルの1クリックで置き換えます。ダブルクリック、Enter、編集、保存、ピン留めで通常のタブになります。
- 外部で作成・名前変更・削除された項目は自動更新します。ツリー右上の「…」から更新、全折りたたみ、現在のファイルの表示、フォルダを閉じる操作ができます。
- ツリーのファイルやフォルダを右クリックすると、切り取り、コピー、パスのコピー、名前の変更、削除（ごみ箱へ送ります。Windows でごみ箱を使えない場所では、完全に削除してよいかを確認します）、プロパティ（Windows のみ）を選べます。フォルダでは「貼り付け」、ファイルでは「開く」「ピン留めして開く」、さらに「ターミナルで開く」、「エクスプローラーで開く」（Mac は Finder。ファイルは「…で表示」）、「新しいファイル」「新しいフォルダ」を選べます。開いているフォルダの最上位は、切り取り・名前の変更・削除ができません。
- ツリーの余白を右クリックすると、「最新の情報に更新」と「すべて折りたたむ」を選べます。
- 名前の変更や移動をしても、開いているタブは新しい場所のファイルに付いていきます。未保存の文書をごみ箱へ送った場合は、内容を残したまま「ディスク上から削除」と表示されます。同じフォルダへコピーしたときの名前は OS が付けます（Windows は「- コピー」、macOS は「のコピー」）。
- `Ctrl+B`（Macでは `⌘B`）でツリーを表示・非表示にします。上下の境界をドラッグして高さを配分でき、サイドバー右端で全体の幅を変更できます。ツリーを隠すとタブ領域が全高を使います。セッション復元が有効なら開いたフォルダ・表示状態・上下比率を次回起動時に戻し、サイドバー幅も保持します。
