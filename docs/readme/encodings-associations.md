# 対応する文字コードとファイル関連付け

開いた文書が UTF-8、UTF-8 BOM、UTF-16 LE／BE、UTF-32 LE／BE、Shift_JIS、EUC-JP、ISO-2022-JP のいずれかであれば、保存時も同じ文字コードを維持します。BOMなしのUTF-16／UTF-32も、NULの配置から安全に判定できる場合は読み込めます。改行コードも CRLF、LF、CR のまま保存されます。

Windows の設定画面では、`.txt`、`.md`、`.pdf`、`.log`、`.csv`、`.json` などを Fumilume に関連付けられます。関連付けると、対象ファイルをダブルクリックして Fumilume で開けます。変更は現在の Windows ユーザーだけに適用されます。macOS では Finder の「このアプリケーションで開く」から選びます。

Fumilume の起動中に別のファイルをダブルクリックした場合は、新しいウィンドウを増やさず、既存のウィンドウへ追加して開きます。同じファイルが既に開いている場合は、タブを増やさず、そのタブへ切り替えます。
