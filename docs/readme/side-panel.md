# 左のパネル

タブ一覧の上にある 3 つのボタンで、左側に出すものを切り替えられます。

- **開いているもの**: 開いている文書・PDF・検索結果・設定のタブ一覧です。設定以外はタブの右クリックメニュー（「タブをピン留め」「ピン留めを解除」）で一覧の先頭へ固定でき（固定したタブはピンの目印が付き、閉じるボタンの代わりになります。閉じるときは `Ctrl+W` か右クリックメニューを使います）、セッション復元の対象になる文書・PDFではピン状態も次回起動時に復元されます。右クリックメニューの詳細は下の「タブの右クリックメニュー」を参照してください。
- **アウトライン**: 本文から拾った見出しの一覧です。Markdown の見出しと、C# や TypeScript などの型・メンバーの宣言に対応しています。行を選ぶとその場所へ移動し、矢印キーで見出しを辿ると本文が追いかけます。対応していない形式ではその旨を表示します。
- **ブックマーク**: `Ctrl+F2` で付けた印の一覧です。行番号とその行の内容が並び、選ぶとその行へ移動します。

最後に開いていたパネルは次回起動時にも復元されます。
左パネルと本文の境界をドラッグすると、パネル幅を120～480pxの範囲で変更できます（上限はウィンドウ幅によって変わります）。選んだ幅は次回起動時にも復元されます。

## タブの右クリックメニュー

「開いているもの」のタブを右クリックすると、次の操作を選べます（Mac では `Ctrl` を `⌘` に読み替えます）。

- **新しいタブを下に開く**
- **ピン留め**: タブをピン留め・解除します（設定のタブなど、固定できないタブには出ません）。
- **閉じる**: 「タブを閉じる」（`Ctrl+W`）、「下側のタブを閉じる」、「他のタブを閉じる」。
- **タブの詳細操作**
  - 上側のタブを閉じる、ピン留めされていないタブをすべて閉じる
  - すべてのタブをピン留め、すべてのピン留めを解除、上側・下側のタブをピン留め
  - すべてのタブ・上側・下側のタブを開き直す（ディスク上の内容を読み直します）
  - 先頭へ移動、末尾へ移動、名前順・パス順に並べ替え、並び順を反転
  - 親フォルダをフォルダツリーで開く
  - コピー各種: タブ名、file URI、Markdown リンク、すべてのタブのパス
- **閉じたタブを開く**（`Ctrl+Shift+T`、Mac は `⇧⌘T`）と **最近閉じたタブ**: 直近に閉じたタブを開き直します。閉じたタブの履歴はアプリを閉じると消えます。
- **ファイル操作**（ディスク上のファイルのタブのみ）: 切り取り、コピー、パスのコピー、名前の変更、削除、プロパティ（Windows のみ）、ターミナルで開く、エクスプローラーで表示（Mac は Finder で表示）。まだ保存していない文書では、ディスク上のファイルが要る項目は選べません。

タブ一覧の何もない余白を右クリックすると、「新しいタブ」（`Ctrl+N`）と「閉じたタブを開く」を選べます。

### ファイル操作と開いているタブ

- 名前の変更や移動をしても、開いているタブは新しい場所のファイルに付いていきます。
- 削除はごみ箱へ送ります。未保存の編集があるタブは、編集中の内容を保ったまま「ディスク上から削除」と表示されます。
- コピーを同じフォルダへ貼り付けたときの名前は OS が付けます。Windows は「- コピー」、macOS は「のコピー」が付きます。
