# フォルダツリー

フォルダツリーは文書内の面とは別のワークスペースナビゲーションで、左サイドバーの下段に置き、上段に縦タブを表示します。`SidePanelKind` の各面は同時に1枚だけ表示し、ツリーを開いてもタブ一覧を隠しません。起動時はエクスプローラーを表示し、未選択時とフォルダを閉じた後は「フォルダを開く」ボタンを表示します。幅は既存の `SidePanelWidth`（120～480px）を上下で共有し、ウィンドウ幅に応じて上限を下げて本文列に480pxを確保します。`SidebarRoot` は上段・6pxの行分割線・下段を持ち、上下の高さをドラッグで調整できます。上段は96px、下段は140pxを最小とし、非表示中は下段と区切りを0pxへ畳んで上段を全高へ広げます。未選択時もCtrl+Bとパレットから表示を切り替えられます。

`MainWindowViewModel.Folder.cs` が単一のルートと選択・展開を管理し、`FolderTreeService` が背景処理で直下のディレクトリだけを列挙します。ディレクトリのreparse pointは展開せず、循環を避けます。読めないディレクトリは項目に理由を表示します。`FileSystemWatcher` は作成・削除・名前変更を250msで集約し、読込済みのノードを更新します。監視通知と手動更新は進行中の更新タスクを共有し、途中で届いた追加要求の反映まで待ちます。ノードは同一パスで再利用して展開状態を保ち、ルート変更・閉じる・終了時に監視と読込を破棄します。非表示中は選択文書を表示する走査を保留します。

ツリーのファイルオープンは文書/PDF共通の既存読込と `_openPathsGate` を使います。1クリックで `WorkspaceTabViewModel.IsPreview` の一時タブを開き、読込に成功した後で以前の未編集プレビューだけを閉じます。ダブルクリック・Enter・編集・保存・ピン留め、または他の経路から同じファイルを開くと通常タブに確定します。終了時は一時タブも通常の文書/PDFとして保存し、再起動時には通常タブとして復元します。`SessionState` の任意プロパティ `FolderPath`・`FolderTreeVisible`・`SidebarSplitRatio`（既定0.5、範囲0.1～0.9）で上下比率を復元します。旧版の `FolderTreeWidth` は互換性のためだけに保ちます。回復用セッションにも上下比率を引き継ぎます。

フォルダ操作の表示名は `EditorCommandCatalog.WorkspaceCommands` へ置き、コマンドパレットとツリーの操作メニューを入口にします。フォルダを開く操作には `Ctrl+K, Ctrl+O`（macOSでは `⌘K, ⌘O`）、ツリー表示切替には `Ctrl+B`（macOSでは `⌘B`）を割り当て、既存の `Ctrl+Shift+E`（行削除）を維持します。
