# 重要な不変条件

- テキスト文書は、利用者が選び直さない限り、対応範囲内で読込時の文字コードと改行コードを保存後も維持する。
- 行番号・アウトライン・Markdown解析・行単位編集は、CRLF・LF・CRを同じ行区切りとして扱う。
- 未保存文書のタブを個別に閉じる前に、保存・破棄・取消の決定を完了する。アプリ終了時は、セッション復元が有効なら未保存の内容を控えへ引き継ぎ、無効なら同じ決定を完了する。
- セッションを控える設定では、未保存の本文を控えへ書けたことを確認してから終了する。書けない場合は終了しない。
- セッションの控えは、新しい一覧を確定させたあとにだけ古い版を消す。
- 同じユーザーの通常起動は単一プロセスへ集約し、後続起動のファイル引数は初回復元後の既存ウィンドウへ渡す。転送できなかった場合は利用者へ通知する。
- 文書・PDFタブは、大文字・小文字を区別しない絶対パスごとに最大1個とする。
- ファイル操作（改名・移動・削除）の後も、文書・PDFタブはパスごとに1個で、新しいパスを指す。
- ファイル操作で未保存の本文を失わない。削除された未保存文書はタブに残す。
- 削除はごみ箱へ送り、ごみ箱に送れない場合に黙って完全削除しない（Windowsはシェルの確認に従う）。
- 設定タブは最大1個で末尾にあり、コンテンツタブが0個の状態を作らない。
- フォルダ横断検索の結果は中央のタブに出し、左サイドパネルへ移さない。
- 常時出すツールバーは、新規・開く・保存・元に戻す・やり直す・検索・設定に限定する。他の機能の入口はコマンドパレットと右クリックメニューにする。
- アウトラインは対応する拡張子だけを解析し、判定できない形式では空を返す。
- マクロの再生中は記録しない。1 回の実行はひとつの取り消し単位にする。入力を尋ねるコマンドは記録しない。
- PDFの不変条件は [PDF](pdf-viewer.md) を参照する。
- Markdownプレビューは `.md` だけに提供し、編集元テキストを変更しない。
- UIフォントとエディタフォントは独立し、エディタ候補は等幅フォントだけにする。
- 設定保存の失敗で既存の正常な設定ファイルを途中内容へ置き換えない。
- x64とARM64の成果物は同じアプリ版を持ち、それぞれ対応する更新チャンネルへ公開する。
