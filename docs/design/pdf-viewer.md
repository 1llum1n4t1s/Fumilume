# PDF

`.pdf` は Windows では `WindowsPdfRenderer` が `Windows.Data.Pdf`、macOS では `MacPdfRenderer` が Core Graphics で開き、要求ページをビットマップへ変換します。PDFは閲覧専用で、編集・保存の対象にはしません。

## 表示とレンダリング

全ページを縦につなげた連続スクロールで表示し、配置は開くときに取得した全ページの寸法だけから `PdfPageLayout` が計算します（ページ間隔12 DIP、外周の余白24 DIP、ページは横中央寄せ）。画像化とViewへの載せ込みは表示範囲とその前後1ページに限り、表示範囲から3ページまでは画像を控え、それより外と画素数の上限を超えた分は表示中心から遠い順に破棄します。メモリ使用量はページ数に比例しません。

描画は倍率と表示の拡大率ごとの世代で直列に1枚ずつ、表示中心に近いページから行います。倍率か拡大率が変わったときだけ世代を進めて描き直し、スクロールでは描き直しません。失敗したページは画像を空にしてそのページだけにエラーを示し、倍率か拡大率が変わるまで再試行しません。古い世代・破棄済み・範囲外の結果は捨てます。

倍率は全ページ共通で、25～400%の手動拡大率と、最も幅の広い／高いページを表示領域へ収めるフィットを管理します。フィット倍率は手動倍率の範囲外も許容し、表示寸法は縦横比を維持します。

配置・スクロール位置・文字選択の座標はDIPで扱い、画像は「倍率×表示の拡大率（`TopLevel.RenderScaling`）」のデバイス画素で描きます。ページの表示寸法はデバイス画素の整数へ切り捨てて揃え（`PdfPageLayout`）、画像とレンダラーは同じ計算を使うため、画像は画素と1対1で表示されます。拡大率はViewが表示領域と一緒にViewModelへ渡し、拡大率の変更（別の拡大率のモニターへの移動を含む）では表示上端の位置を保って描き直します。選択していないタブは選んだときに追従します。画像の確保量は1辺8192画素の上限で抑え、超える場合は縦横を共通の係数で縮めて表示側で引き伸ばします。

## スクロールとページ

スクロール位置の正本はViewModelが持つページ基準のアンカーで、Viewへは要求として渡し、適用結果を受け取ります。PDFタブは `ScrollViewer` を共有するため、タブを選んだときにその位置を当て直します。現在のページは表示中心を含むページ（ページ間隔は次のページ、最上端は1ページ目、最下端は最終ページ）とし、前後ボタン・ページ番号入力で明示移動した直後はそのページに固定します。セッションには表示方式と、表示上端のページ・そのページ内の割合を保存し、旧形式の正の倍率は固定倍率、割合のない控えはそのページの先頭として復元します。

## 文字選択とコピー

`PdfTextService` が純C#のPdfPigからページの文字と位置を抽出し、各ページの `PdfTextSelectionLayer` が画像と同じ寸法へ座標を対応させて選択範囲を重ねます。抽出は画像とは別の優先度の低い直列ループで、表示中のページを中心に近い順に読み、控えは32ページまで（選択中・表示中のページは残す）です。選択はページ内に限り、選択状態とページ番号は `PdfDocumentViewModel` が保持し、コピーは `IEditorDialogService` 経由でクリップボードへ渡します。

スクロール・ページ移動・ズームでは選択を解除せず、別ページの文字以外のクリック・Esc・タブを閉じたときに解除します。見えなくなったページの選択も文字の控えを保ち、コピーできます。抽出はUIスレッド外で直列化し、取消・タブ閉鎖後の結果は破棄します。文字がないページやコピー禁止のPDFは選択せず、抽出失敗でも画像の閲覧を維持して状態を表示します。複雑な段組や文字対応情報がないPDFでは、コピー順序や文字を完全に復元できない場合があります。

## 不変条件

- PDF選択中はテキスト編集・保存操作を有効にしない。
- 全ページを同時に画像化しない。画像は表示範囲の近くのページだけに限る。
- スクロール位置の正本はアンカーとし、共有 `ScrollViewer` の値にしない。
- 文字選択は1ページ内に限る。
