# 設定画面の検索

設定画面は設定タブが初めて開かれるときに生成し、フォント候補の列挙・書体判定・検索索引構築を通常の文書起動から外します。同じ窓では1個の `SettingsView` を保持して `SettingsTab` の変更時に DataContext だけを更新し、設定タブを閉じて開き直しても検索語と選択カテゴリを維持します。

設定は 6 タブに分かれ、`SettingsView` が読み込み時にカード単位の索引を作り、検索語に当たったカードとタブだけを残します。OS限定の表示条件はカードの親に保持し、検索時も非表示の親を持つカードは表示・件数から除外します。走査に視覚ツリーを使わないのは、`TabControl` が選んでいないタブの中身を組み立てないためで、`SettingsSearch` は XAML の読み込み時点で埋まっている `Content` と `Children` だけを辿ります。照合対象には項目名だけでなく補足文も含めます。
