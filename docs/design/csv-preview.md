# CSV

## 表示と単一セル編集

`.csv` はMarkdownと共通の `TogglePreviewCommand`（`Ctrl+Shift+M`）でセル値を修正できる表へ切り替えます。`CsvDocumentParser` が引用符内のカンマ・改行・二重引用符を解析し、`CsvPreview` が行番号とExcel形式の列名を持つAvaloniaコントロールとして描画します。先頭行もデータとして扱い、数値・日付への変換や数式の実行は行いません。編集元テキスト、文字コード、改行コードを維持し、セッションの `IsCsvPreview` で表示状態を復元します（既存の `IsMarkdownPreview` の保存形式も維持）。

セルのダブルクリックまたは Enter で編集欄を開き、適用時に `DocumentViewModel.TryUpdateCsvCell` が表示時の本文との一致を検証します。パーサーが保持する元フィールドの範囲だけを `EditorDocument.Replace` で置換し、他セルの表記や行区切りを維持します。値内の改行は文書の改行形式へ揃え、必要に応じて引用符を付けます。Undo/Redoはセル適用を1操作とし、未適用の入力は表示・タブ・元本文の変更時に取り消します。

## 表示上限と性能

プレビューは先頭1,000行・100列を保持し、超過時に全体件数と表示範囲を案内します。上限外は文字列値を実体化せず、件数・引用符状態・位置だけを走査します。解析結果は同じ本文に対して再利用し、本文変更時に破棄します。単一セル更新はキャッシュの元フィールド範囲を直接置換します。大きな入力の解析はキャンセル可能な背景処理で行い、本文・文書・表示状態が変わった古い結果は適用しません。

罫線と固定見出しを描画し、画面内のセルだけを生成します。セル表示は512文字、ツールチップは4,096文字までとし、省略時は編集画面での確認を案内します。未閉じ引用符は `CsvDocument.HasUnterminatedQuotedField` で表示へ伝えます。上限外へ行・列を追加しても挿入位置を変更せず、編集画面での確認を案内します。

## 行列編集とコピー

行・列の追加と削除は `CsvTableEditingService` が全文の元フィールド位置・レコード位置から変更後の本文を組み立て、`DocumentViewModel` のPrepare APIで準備し、`TryApplyPreparedCsvEdit` が1回のUndo操作として反映します。列操作は表示上限を越えた全行へ適用します。未閉じ引用符があるCSVへの構造編集は拒否します。行・列の選択とShift連続選択は見出しから行い、`GetCsvCellRangeTextAsync` で引用符付きTSVにしてコピーします（行内の全列、列内の全行を含み、CSV本文に影響しない）。

見出しのコンテキストメニューに前後への追加・選択範囲削除・コピーを置き、空表にも追加の入口を出します。複数選択時の追加数は選択数に合わせます。末尾への行・列追加は `EditorCommandCatalog` とパレットからも実行でき、マクロはViewを使わず同じ文書操作へ再生します。列幅・行高は見出し境界のドラッグで変更するタブ別の一時表示状態で、CSVとセッションへ保存しません。

矩形範囲は `CsvCellRange` で表し、コピー・消去・下／右フィル・TSV貼り付けを `CsvTableEditingService` と `DocumentViewModel` へ集約します。貼り付けは矩形範囲の左上を起点とし、ExcelのTSVとして明示解析します。空値もTSVで引用して末尾の空行を保持し、足りない行列や欠落セルは補完し、変更対象外の元フィールド表記は保持します。各変更は1回のUndoにまとめ、非同期クリップボードの完了時は文書・本文・選択の一致を再確認します。

全文を使う表操作は、本文・TSVを各8,388,608 UTF-16文字、セル数を各1,048,576個に制限し、結果も同じ上限で拒否します。失敗時は本文を変更しません。128 Ki文字以上はキャンセル可能な背景処理で準備し、UIスレッドで元本文・改行・文書・選択を照合してから反映します。本文変更、選択変更、タブ切替、非表示化では古い処理を取り消し、重複操作を抑止します。マクロの末尾追加も同じ準備・反映経路を使い、手順は開始時に複製し、非同期準備中はUndoグループを閉じ、再開時は同じグループ識別子の場合だけ継続します。

## ソートと操作

ソートは選択した1列を基準に、表示上限外も含めてレコード全体を安定ソートします。先頭行を含む操作と固定する操作を明示的に分け、ヘッダーを推定しません。数値はInvariantCultureのdecimal、その他はOrdinalIgnoreCaseで比較し、昇順は数値、文字の順、降順は逆順です。空欄・欠落値は常に末尾に置きます。元フィールドの表記と各位置のレコード区切りを維持し、末尾の改行なし空レコードやCR＋LF結合の空レコードは空文字の引用表記で消失を防ぎます。パレットでは列番号を尋ねるためマクロへ記録しません。

セル選択はクリック・Shift・ドラッグ、移動は矢印・Tab、編集開始はEnter/F2です。編集欄のEnter/Tabで適用して次セルへ移動し、Alt+Enterで値内改行を挿入します。CSV表示中はテキスト用 `RunEditorCommand` をCanExecuteと実行時の両方で無効にします。テキスト操作を含むマクロは編集画面へ切り替えて再生し、行列追加だけのマクロはプレビューを維持します。
