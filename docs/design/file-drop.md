# ファイルのドロップ

`MainWindow` はローカルパスを持つ `IStorageFile` だけを受け付け、フォルダを除外します。拡張子の制限は設けず、`.pdf` はPDF、それ以外は通常のテキスト読込へ渡します。開くダイアログも「すべてのファイル」を既定のフィルターにします。

Avalonia のドロップイベントは Bubble のため、`TextArea` のクラスハンドラーで AvaloniaEdit の文字挿入より先にファイルを受け、混在する文字列を本文へ挿入しません。ファイルを含まない文字ドロップはエディタへ任せ、ファイルの受付は `EnableTextDragDrop` と独立して有効にします。受け取ったパスは `OpenForwardedArguments` へ渡し、初回セッション復元を待って既存の直列オープン経路で処理します。
