# アウトライン解析

`OutlineService` は Markdown の見出し（ATX と Setext、フェンス内と YAML 前書きは除く）と、波括弧で入れ子を作る言語の型・メンバー宣言だけを拾い、判定できない拡張子では空を返します。後者は構文解析ではなく行単位の照合で、注釈と文字列の中身を落としてから波括弧を数えて入れ子の深さを決めます。制御構文や呼び出しを宣言と読み違えないよう、宣言の手前に語が無い行と、`throw` や `await` などの語を含む行は落とします。中途半端に拾った一覧は「ここに無いなら本文にも無い」と誤読させるため、拾えることより誤って拾わないことを優先します。

行は逐次列挙し、2000項目で解析を打ち切ります。MarkdownのSetext見出しには1行の先読みを使います。先頭の前書きは閉じる区切りが存在するときだけ除外し、閉じていない場合は本文として解析します。
