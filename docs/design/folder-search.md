# フォルダ横断検索

`GrepService` が指定フォルダのファイルを列挙し、`IDocumentFileService` を通して読み、行単位で照合します。読み込み経路を文書と共有するのは、文字コードの判定を開いたときと一致させるためです。先頭512バイトにNULを含むファイルはバイナリとして除外しますが、BOMまたは安全なバイト配置でUTF-16／UTF-32と判定できる場合は文書と同じデコーダーへ渡します。16MBを超えるファイルと読み取りに失敗したファイルも数えて飛ばし、1件の失敗で検索全体を止めません。一致は5000件で打ち切り、打ち切りと除外の件数を結果へ添えます。

結果は `GrepResultTabViewModel` として文書・PDF・設定と同じ縦タブへ並べます。照合は `Task.Run` で UI スレッドから外し、行を選ぶと `MainWindowViewModel` が該当ファイルを開いて（既に開いていればそのタブを選び）、一致した桁へカーソルを置いて行全体を選択します。

全文の行配列を作らず、`DocumentNewLines.EnumerateLines` でCRLF・LF・CRと末尾の空行を逐次処理し、改行と4096文字ごとの走査点でキャンセルを確認します。
