# 配布の作業先と清掃

- Windowsの発行前に、導入済みVisual Studioの`vcvarsall.bat`でRIDに対応するC++環境を初期化し、Native AOTへリンカー・ライブラリを渡します。
- 配布スクリプトは `WorkRoot`（既定はOSの一時フォルダー配下の `Fumilume/<task-id>`）へツール・配布物・検証環境を出力し、`RecordRoot`（既定は `TaskArtifacts/Fumilume/<task-id>`）へ再開記録と清掃台帳を残します。事前確認・本実行・再開には同じ2つのパスを指定します。
- リポジトリ、Codexユーザーディレクトリ、リンクを含む保存先と禁止名のフォルダーは作成前に拒否します。
- 清掃は検証済みの作業範囲に限定し、Prunlet CLI でファイル単位で行います。既存の配布・検証ファイルが残る場合は停止し、清掃してから同じ作業先で再開します。
