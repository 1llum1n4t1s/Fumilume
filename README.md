# Fumilume

Kiriha の Chrome ライクな垂直タブ UI を受け継いだ、Windows 用の軽量テキストエディタです。文書タブ、パス表示、コマンドバー、編集領域、ステータスバーを 1 画面にまとめています。

## 主な機能

- 複数文書を左側の垂直タブで切り替え
- UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE の読み込みと文字コード維持
- CRLF / LF / CR の改行コード維持
- 新規作成、複数ファイルを開く、保存、名前を付けて保存
- 未保存文書を閉じるときの保存確認
- 行番号（既定で表示）、右端での折り返し、空白・タブ・改行記号の表示切り替え
- 元に戻す / やり直す、検索 / 置換、指定行への移動
- 対応するテキストファイルを拡張子ごとに関連付け
- 大きな文書でも表示行だけを描画する仮想化エディタ
- 行・列、行数、文字数、文字コード、改行コードの表示
- Windows のライト / ダークテーマとアクセントカラーへの追従

## 使い方

```powershell
dotnet run --project src/Fumilume/Fumilume.csproj
```

文書はツールバー、または `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` で操作できます。`Ctrl+W` で現在の文書を閉じます。編集では `Ctrl+Z` / `Ctrl+Y`、検索では `Ctrl+F` / `Ctrl+H`、指定行への移動では `Ctrl+G` を使用できます。次・前の検索結果へは `F3` / `Shift+F3` で移動します。ファイルの関連付けは、ツールバー右側の「オプション」から設定できます。

## 動作環境

Windows 10 バージョン 1809 以降（x64 / ARM64）。配布版は Velopack によりインストールされ、自動更新されます。
