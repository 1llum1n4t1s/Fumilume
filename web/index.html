Fumilume（フミルメ）は、Chrome のような垂直タブで文書を行き来できる Windows 用テキストエディタです。 開いたファイルの文字コードと改行コードはそのまま保たれ、保存しても勝手に書き換わりません。

完全無料 · 広告なし · アカウント登録なし

Features

メモ帳の手軽さに、本気の編集機能を。

起動してすぐ書けるのに、必要になったときの道具はひととおり揃っています。

🗂️

迷わず使える垂直タブ

開いた文書は左の縦一列に並びます。長いファイル名も途中で切れず、何枚開いても一覧のまま。次に開いたときは前回のタブとカーソル位置から再開できます。

Ctrl+NCtrl+OCtrl+W
🈚

文字コードも改行コードもそのまま

UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE を読み分け、CRLF / LF / CR の改行もそのまま保って保存します。開いて閉じただけで差分が出る、が起きません。

UTF-8BOM 維持CRLF / LF
🔤

変換コマンドがひととおり

大文字 / 小文字、全角 / 半角、ひらがな / カタカナ、TAB と空白、Base64、URL エンコードまで。選んだ範囲を狙って変換できます。

Ctrl+F7Ctrl+F6Base64
⌨️

コマンドパレットで一発呼び出し

覚えきれないコマンドは名前で検索。ツールバーは編集・変換・挿入・検索移動のカテゴリごとに分かれているので、目でも辿れます。

Ctrl+Shift+Pあいまい検索
🔖

行の操作とブックマーク

行の二重化・削除・並べ替え・重複マージ・インデント。目印を付けた行へ F2 で飛べて、パターンに一致する行へまとめて印を付けることもできます。

Ctrl+IF2Ctrl+G
🔍

探す・置き換える

大文字小文字の区別や正規表現に対応した検索と置換。対応する括弧へのジャンプや、指定行への移動もすぐ呼び出せます。

Ctrl+FCtrl+H正規表現
⚙️

細かいところまで設定できる

行番号・折り返し・空白や改行記号の表示、桁の縦線、行の高さ、タブの厚み、フォント、インデント幅、矩形選択や仮想スペースまで、設定画面から切り替えられます。

6 タブ構成設定は即反映
⚡

軽快なネイティブ起動

.NET Native AOT による単一ネイティブバイナリ。ランタイム不要で起動が速く、x64 / ARM64 の両方にネイティブ対応します。表示中の行だけを描く仮想化で大きな文書も軽いままです。

Native AOTx64ARM64
🔄

いつでも最新版に

起動時に更新を自動チェック。新しいバージョンはダイアログからダウンロード・適用・再起動まで完結します。テーマは Windows のライト / ダークに追従します。
